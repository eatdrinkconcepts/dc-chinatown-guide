# Logo and QR code — usage

## Lion's Path logo (`logo.svg`)

This is The Lion's Path organization's own mark, as used on the back page of the print guide (red lion and wordmark on a cream ground). A PDF variant also exists in the source tree (`logo.pdf`, `logo-cream.pdf`) but was not required for the print guide; the web build should use `logo.svg`.

Use it to identify The Lion's Path on the site header, footer, and About page only. It is not a restaurant endorsement mark, not a partnership badge, and should not be placed on a restaurant detail page in a way that suggests the restaurant is affiliated with, sponsored by, or offering anything through Lion's Path.

Do not recolor the mark in a way that breaks the established red-on-cream (or cream-on-red) treatment used in the print guide, and do not lock up the logo with a restaurant's branding.

## Instagram QR (`ig-qr.svg`, `ig-qr.png`)

The QR encodes `https://www.instagram.com/lionspathdc/`. In the print guide it appears on the back page, dark cream modules on Lion's Path red (`#8F2C1F`) against the cream page (`#F8EFD9` in the PNG). Use the same destination everywhere: the site should point people to Instagram @lionspathdc, not to a website or email address.
